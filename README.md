# Raíz cuadrada de 1

UNO multijugador en tiempo real con Flutter y Firebase.

## Características

- Salas multijugador en tiempo real (Firebase Realtime Database)
- Autenticación con Google (Firebase Auth)
- Invitaciones por correo
- Chat en sala
- Reglas completas de UNO

## Desarrollo

```bash
flutter pub get
flutter run
```

## Build Android

```bash
flutter build apk --release
# Salida: build/app/outputs/flutter-apk/squareroot1.apk
```
